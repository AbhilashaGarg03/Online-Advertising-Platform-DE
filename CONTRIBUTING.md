# Contributing to Online Advertising Platform

Thank you for your interest in contributing to this data engineering project!

## How to Contribute

### Reporting Issues
- Describe issues clearly with stack traces
- Provide Kafka and database logs if relevant
- Specify system configuration

### Submitting Changes

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Install dependencies: `pip install -r requirements.txt`
4. Test your changes thoroughly
5. Ensure all systems are functioning properly
6. Push and submit a Pull Request

## Code Guidelines

- Follow PEP 8
- Document architecture changes
- Include performance metrics
- Test with realistic data volumes

## Areas for Contribution

- Improving auction algorithms
- Performance optimization
- Enhanced monitoring
- Better documentation
- New features or integrations
- Bug fixes

## Pull Request Process

1. Test with sample data
2. Verify Kafka and database connections
3. Check performance impact
4. Update documentation

Thank you for contributing! 🙏
